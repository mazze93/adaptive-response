This prototype's buildSystemPrompt() and validateAdaptiveResponse() mirror packages/schema exactly. To productionize:

  1. Move the JSON contract server-side into apps/api/src, call the Anthropic SDK there with this same system prompt, then run AdaptiveResponseSchema.parse() instead of the hand-rolled validator here.
  2. Replace the direct window.claude.complete call with new AdaptiveClient({ baseUrl }).respond({ query }), so the browser never holds an API key.
  3. On invalid JSON/schema mismatch, return the Worker's existing 502 — this prototype's error state already matches that UX.
  4. The render order (banner → clarifying → tldr → sections → assumptions → risks → alternatives) is copy-identical to ResponseRenderer — swap for the real component once wired to live data.
